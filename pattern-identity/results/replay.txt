The bytes are identical. The name is not.
==============================================================================
Drain reports change_type='none' on step 4, so a pipeline keying on the
template, or on a hash of it, writes two different names for one line while
being told the cluster held steady. An alert, dashboard, budget or join built
on the step-1 name matches zero events from step 2 onward, and a query that
matches zero events returns a number rather than an error.

Mechanism, from drain3/drain.py: create_template(seq1, seq2) returns
[token2 if token1 == token2 else param_str ...] and writes the result back to
the cluster. A template is the running intersection of every line that ever
matched it, so it can only lose literal tokens, and it loses them whenever a
sibling arrives. Sibling arrival order is a property of the stream.

Scope: this is one statement family in one process. How often two processes
end up on different names is measured by the split-instance benchmark in this
repo; the identifier consequence is measured in bench/identifier.py. Drain's
templates are good. What moves is the moment at which each one settles.

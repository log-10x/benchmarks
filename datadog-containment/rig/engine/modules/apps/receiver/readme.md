## 1️⃣0️⃣❎ Receiver app

Receive log/trace events from a coupled forwarder; in read-only mode emit metrics only, in read-write mode also receive and optionally compact events before they ship to output.

To learn more see the Receiver [app documentation](https://doc.log10x.com/apps/receiver "Receive log/trace events from a coupled forwarder; in read-only mode emit metrics only, in read-write mode also receive and optionally compact events before they ship to output").

# Apps

Start with the [**MCP Server**](https://doc.log10x.com/apps/mcp/). Install it into Claude Desktop, Code, or Cursor and it discovers your environment and sets up the capabilities below. Each can also be installed manually.

<div class="grid cards" markdown>

-   :material-robot-outline:{ .lg .middle } **MCP Server**

    ___

    The orchestration entry point that sets up and runs the capabilities below.

    [:octicons-arrow-right-24: Learn more](https://doc.log10x.com/apps/mcp/)

-   :material-chart-bar:{ .lg .middle } **Reporter**

    ___

    Shows which event types drive cost, before the analyzer.

    [:octicons-arrow-right-24: Learn more](https://doc.log10x.com/apps/reporter/)

-   :material-pipe-valve:{ .lg .middle } **Receiver**

    ___

    Acts on each pattern: pass, sample, compact, tier_down, offload, or drop.

    [:octicons-arrow-right-24: Learn more](https://doc.log10x.com/apps/receiver/)

-   :material-cloud-arrow-right-outline:{ .lg .middle } **Retriever**

    ___

    Offloads events to your own S3 and fetches the exact lines back on demand.

    [:octicons-arrow-right-24: Learn more](https://doc.log10x.com/apps/retriever/)

</div>

Logs diagnostics and publishes health metrics from pipeline [units](https://doc.log10x.com/engine/pipeline/#units).

Each unit emits counters (scanned symbols, input events) and states (scan errors), periodically logged and published to the [metric output](https://doc.log10x.com/run/output/metric/) the pipeline configures.

Defines a list of input folders to recursively [scan](https://doc.log10x.com/compile/scan/) for source/binary files.
Input folders may contain files and sub-folders pulled from [GitHub](https://doc.log10x.com/compile/pull/github/), [Artifactory](https://doc.log10x.com/compile/pull/artifactory/) and [S3](https://doc.log10x.com/compile/pull/s3/).
